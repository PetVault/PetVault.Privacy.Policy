# PetVault Privacy Policy

This repository hosts the official Privacy Policy web page for the **PetVault** mobile application (`com.petvault.app`), deployed via GitHub Pages.

- **Live URL:** [https://petvault.github.io/PetVault.Privacy.Policy/](https://petvault.github.io/PetVault.Privacy.Policy/)
- **Main App Repository:** Private Repository (`PetVault.App`)

---

## 🔒 Summary of Privacy Practices

* **Local-First Storage:** All pet records, vaccine histories, weight logs, and pet avatars are stored locally on the user's device (`expo-sqlite` and `expo-file-system`).
* **Zero Cloud Servers:** No personal pet data or medical records are uploaded to proprietary cloud servers.
* **On-Device OCR:** Certificate scanning processes text locally on the device using native vision OCR engines.
* **Third-Party Services:** Google AdMob (banner ads) and RevenueCat (in-app billing) standard privacy policies apply.
